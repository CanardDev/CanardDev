# Salut, moi c'est Canard

Je développe des plugins Minecraft depuis un moment, surtout pour Paper et en Skript. Je fais aussi des packs de textures et des modèles 3D.

La plupart de mes projets tournent sur **TrajWorld**, le serveur où je suis admin. C'est là que je teste tout avec de vrais joueurs, Java comme Bedrock.

### Ce que je fais
- Des plugins Java pour Paper 1.21+ : menus, économie, claims, anticheat, events
- Des scripts Skript sur mesure
- Des textures et des modèles 3D avec Nexo, qui marchent aussi sur Bedrock

### Quelques projets

**Claims**
Un système de claims pensé pour être simple pour les joueurs : rôles, permissions par joueur, zones à louer, banque de land. Tout se gère depuis des menus.
